# SMSAnalyzer v0.1.98

- Categories show Credits first, Debits second, then remaining categories alphabetically. Cards use each category's selected colour, with a 3px left border and 1px on the other sides.
- Pull-to-refresh shows the shared animated hourglass over a translucent black overlay, prevents duplicate refresh taps, and cleans up on completion, error or a two-minute timeout.
- Settings themes are ordered Wood, BookShelves, Brick, Stone.

This release uploads the existing signed v0.1.98 APK, previously installed successfully on the connected S25. No rebuild or tests were run for this publication.
