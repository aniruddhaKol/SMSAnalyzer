# Screenshot provenance

The screenshots in `screenshots/` show the actual v0.1.54 HTML/CSS interface rendered at a 393 × 852 CSS-pixel viewport with 2× pixel density. They use synthetic SMS fixtures and a fixed sample clock, not a real inbox or personal training export. The reproducible capture script is `scripts/capture-screenshots.cjs`.

The Wood, Stone and Brick themes are existing app assets. The native Android status/navigation bars and system permission dialogs are outside these WebView screenshots. Browser-only Settings correctly shows SMS access as not enabled.
