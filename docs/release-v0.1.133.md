# SMSAnalyzer v0.1.133

- Recognise scheduled autopay notices as upcoming bills, categorise bill notices consistently as Bills & Utilities, and consolidate matching card statements/reminders while keeping original SMS.
- Show due amounts in red across Alerts and individual/combined bill SMS views. Due-date badges share the compact calendar pill used in Trends.
- Improve standard merchant identification for Uber and Paytm variants; add offline UMANG, Netflix, Delhi Metro and MF Utilities icons.
- Match self-transfer counterparts by transaction reference, amount, direction and time. Transfers remain excluded from expenses/budget and incoming self-transfers from credits; their spending-exclusion switch stays checked and disabled.
- Refresh default category icons while preserving user-selected icons; Travel defaults to the compass.
- Show the shared hourglass before initial SMS import/analysis. Update only author contact buttons to TaskVilla styling and link handling, retaining SMSAnalyzer support email content.
- Shorten Trends headings to Spend by category and Spend by weekday, keep them on one line, and align their calendar duration pills vertically.

This release reuses the existing signed v0.1.133 APK installed on the phone. No rebuild or tests were run for this publication. Documentation screenshots remain synthetic v0.1.127 renders.
