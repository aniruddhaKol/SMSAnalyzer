# SMSAnalyzer v0.1.109

- One alphabetically sorted category ruleset per category, including empty sets created with new categories. Combined entity/keyword editing retains existing per-match account, history and priority restrictions.
- Category deletion removes its associated reusable rules and ruleset. Original SMS remain in the local archive; affected classifications fall back to Others unless another explicit correction applies.
- Rule matching uses compiled conditions and incremental background analysis for supported changes, with the shared animated hourglass and finite timeouts.
- Unsaved editor changes offer Discard / Save on Back, closing and Android navigation. Failed saves retain the draft. Matching-value removals require confirmation and remain draft-only until saved.
- Individual SMS corrections support Edit without becoming reusable rules. Additional options reuse the shared themed switches.
- Shared sculpted Add, Back, Edit, Remove, Close, Save and Preview artwork; corrected Rules navigation and scroll restoration.
- Remove confirmations use TaskVilla's pale-red bevel and a text-only Remove label.

Published using the existing signed v0.1.109 APK previously installed on the S25. No APK rebuild or tests were run for this publication. Existing README screenshots remain explicitly labelled as older synthetic renders.
